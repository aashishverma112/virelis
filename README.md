# Virelis - Creative Frontend Developer Assignment
Virelis is a premium biotechnology landing page created as part of the Creative Frontend Developer interview assignment.
The idea was to create a website that feels like a real biotechnology company rather than a typical portfolio or template, with a strong focus on visual design, motion, interaction, and responsive frontend development.

## Live Website
https://virelis-livid.vercel.app/

## Tech Stack
- Next.js
- React
- TypeScript
- CSS
- GSAP

## Features
- Responsive biotechnology landing page
- Animated biological particle visualization
- Scroll-based animations and section reveals
- Animated biological wave visual
- Interactive navigation and CTA elements
- Research and technology cards
- Impact statistics with custom icons
- Final CTA with animated particle field
- Smooth scrolling and micro-interactions
- Responsive layouts for desktop, tablet, and mobile

## Design Approach
I wanted the design to feel modern, scientific and premium without making it look overly technical.
The visual language is built around dark and warm off-white surfaces, muted green accents, large editorial typography, generous spacing, and subtle borders.
The page is divided into six sections:
1. Precision Biology
2. Innovation
3. Research & Technology
4. Capabilities
5. Impact
6. Contact
Each section has its own visual treatment while keeping the same typography, spacing, and color system throughout the page. This helps the experience feel like one cohesive website rather than a collection of separate sections.

## Animation Approach
Motion is used to support the content and give the website a sense of life without making it distracting.
GSAP is used for scroll-triggered reveals, transitions, particle movement, and subtle visual effects.
The biological particle field and wave visual are built as interactive elements rather than static images, allowing them to move naturally as the user explores the page.
The animations are intentionally kept lightweight so the page remains smooth while still feeling dynamic.
